# Practical 1: Revisiting Pandas and NumPy

## Aim
To revisit Pandas and NumPy in Python and perform basic DataFrame conversion, array properties and mathematical operations.

## Objectives
- Create a Pandas DataFrame.
- Convert a DataFrame into a NumPy array.
- Explore array shape, size and dimensions.
- Perform arithmetic operations using NumPy.
- Understand matrix operations such as transpose, inverse and matrix multiplication.

## Libraries Used
- **Pandas:** Used for creating and managing DataFrames.
- **NumPy:** Used for numerical computations and matrix operations.

## Practical Implementation

### 1. Import Libraries
Import Pandas and NumPy for data manipulation and numerical operations.

### 2. Create a DataFrame
Create a DataFrame using numerical values with three columns: A, B and C.

### 3. Convert DataFrame to NumPy Array
Convert the Pandas DataFrame into a NumPy array using `to_numpy()`.

### 4. Find Array Properties
Explore the following properties:
- **Shape:** Returns the number of rows and columns.
- **Size:** Returns the total number of elements.
- **Dimension:** Returns the number of dimensions of the array.

### 5. Perform NumPy Operations
Perform the following operations on the array:
- Addition
- Subtraction
- Element-wise multiplication
- Transpose
- Matrix inverse
- Matrix multiplication (dot product)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy

## Conclusion
This practical demonstrates the use of Pandas and NumPy for data handling and numerical computation. It covers DataFrame creation, array conversion, array properties and fundamental mathematical and matrix operations.
