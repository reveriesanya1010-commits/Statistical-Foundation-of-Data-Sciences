#Statistical Foundation of Data Science
## About the Repository
This repository contains 12 practicals completed as part of the Statistical Foundation of Data Science course. It includes Python-based implementations of statistical concepts, data analysis techniques, mathematical models, and data visualization.

The purpose of this repository is to demonstrate the practical application of statistical methods and develop an understanding of their importance in Data Science.

## List of Practicals
Practical No.	Title
01	Revisiting Pandas and NumPy
02	Understanding Foundation of Stats using Rating Dataset
03	Understand Descriptive Statistics
04	Understanding Data with Graphs
05	Understanding Two-Tailed Test
06	Understanding T-Test, ANOVA, Chi-Square
07	Understanding Regression with T-Test and ANOVA
08	Decision Trees and its Maxdepth
09	KNN (K-Nearest Neighbors)
10	PCA (Principal Component Analysis)
11	Monte Carlo and MCMC
12	Deterministic Model
## Tools and Technologies Used
The following tools and Python libraries are used throughout the practicals:

Python – Programming language for statistical computations and analysis.
Google Colab – Cloud-based environment for executing Python notebooks.
NumPy – Numerical computations and array operations.
Pandas – Data manipulation and analysis.
Matplotlib – Data visualization and graphical representation.
Seaborn – Statistical data visualization.
SciPy – Scientific and statistical computations.
Scikit-learn – Machine learning algorithms and data analysis.
## Repository Structure
Each practical is organised in a separate folder containing:

A Colab Notebook (.ipynb) with the practical implementation and outputs.
A README.md file explaining the aim, objectives, methodology, implementation, and conclusion of the practical.
## Learning Outcomes
Through these practicals, the repository demonstrates:

Understanding of fundamental statistical concepts.
Application of descriptive and inferential statistics.
Data manipulation and visualization using Python.
Understanding of hypothesis testing and statistical methods.
Introduction to machine learning techniques and mathematical models.
Practical implementation of statistical methods in Data Science.
## Conclusion
These practicals provide hands-on experience in applying statistical concepts and Python programming to solve analytical problems. They help build a strong foundation in statistics and its applications in Data Science.
