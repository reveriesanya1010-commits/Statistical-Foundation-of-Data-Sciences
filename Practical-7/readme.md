# Practical 7: Understanding Regression with T-Test and ANOVA

## Aim
To study the relationship between teachers' gender, age, beauty scores and teaching evaluation scores using regression analysis, T-test, ANOVA and correlation.

## Objectives
- Understand regression analysis and its application in statistics.
- Examine whether gender affects teaching evaluation scores using a T-test.
- Study whether instructors' beauty scores differ according to age groups using ANOVA.
- Examine the relationship between teaching evaluation scores and beauty scores.
- Understand the interpretation of regression coefficients and p-values.
- Draw conclusions from statistical results using the TeachingRatings dataset.

## Libraries Used
- **Pandas:** Used for data handling and analysis.
- **Statsmodels:** Used for regression modeling and statistical analysis.

## Dataset
TeachingRatings.csv

## Practical Implementation

### 1. Import Libraries
Import Pandas and Statsmodels for data handling, regression modeling and statistical analysis.

### 2. Load Dataset
Load the TeachingRatings dataset into a Pandas DataFrame.

### 3. Regression with T-Test
Build a regression model using gender as a categorical independent variable and teaching evaluation score as the dependent variable. Interpret the regression coefficients and p-values.

### 4. Regression with ANOVA
Divide professors into age groups and build a regression model to analyze beauty scores across the age groups. Perform ANOVA to examine differences between groups.

### 5. Correlation and Regression Analysis
Build a regression model using beauty scores to predict teaching evaluation scores. Analyze the regression coefficients, p-values and R-squared value.

### 6. Interpret Results
Interpret the regression summaries and statistical results to understand relationships between variables.

This practical helped in understanding regression analysis, categorical variables, T-test, ANOVA and the relationship between beauty scores and teaching evaluation scores. Regression models and statistical tests were used to analyze and interpret the data.
