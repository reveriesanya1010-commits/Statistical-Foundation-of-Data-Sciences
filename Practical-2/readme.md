# Practical 2: Understanding Foundation of Statistics Using Rating Dataset

## Aim
To understand fundamental statistical concepts using the Teaching Ratings dataset and perform descriptive statistical analysis and data visualization using Python.

## Objectives
- Understand cross-sectional data.
- Calculate mean, median, minimum and maximum values.
- Generate descriptive statistical summaries.
- Visualize data using a histogram.
- Compare beauty scores based on gender.
- Analyze the relationship between gender and tenure status.

## Libraries Used
- **Pandas:** Used for data manipulation and analysis.
- **NumPy:** Used for numerical operations.
- **Matplotlib:** Used for data visualization.

## Dataset
TeachingRatings.csv

## Practical Implementation

### 1. Import Libraries
Import Pandas and NumPy for data manipulation and statistical analysis.

### 2. Load and Explore Dataset
Load the TeachingRatings dataset and explore its rows, columns, data types and structure.

### 3. Identify Type of Data
Identify the dataset as cross-sectional data because it contains observations of different professors rather than observations over time.

### 4. Calculate Statistical Measures
Calculate the mean, median, minimum, maximum and range of the students variable.

### 5. Descriptive Statistics
Generate a statistical summary of the dataset using the `describe()` function.

### 6. Visualize Beauty Scores
Create a histogram to examine the distribution of beauty scores.

### 7. Compare Beauty Scores by Gender
Calculate the mean and standard deviation of beauty scores for male and female instructors.

### 8. Analyze Gender and Tenure
Create cross-tabulations to examine tenure status across genders and calculate percentages.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Conclusion
This practical helped in understanding fundamental statistical concepts, exploring cross-sectional data, calculating descriptive statistics, visualizing distributions and comparing variables based on gender and tenure status.
