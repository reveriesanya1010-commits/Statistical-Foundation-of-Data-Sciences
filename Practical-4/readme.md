# Practical 4: Understanding Data with Graphs

## Aim
To understand and analyze data using statistical techniques and graphical representations with Python libraries.

## Objectives
- Explore the Teaching Ratings dataset.
- Identify duplicate observations.
- Compare mean age and standard deviation before and after removing duplicate observations.
- Calculate average teaching evaluation scores by course division.
- Visualize the relationship between age and teaching evaluation.
- Analyze data based on gender and tenure using scatter plots.

## Libraries Used
- **Pandas:** Used for data manipulation.
- **NumPy:** Used for numerical operations.
- **Matplotlib:** Used for graphical visualization.
- **Seaborn:** Used for statistical visualization.

## Dataset
TeachingRatings.csv

## Practical Implementation

### 1. Import Libraries
Import Pandas, Matplotlib and Seaborn for data analysis and visualization.

### 2. Load and Explore Dataset
Load the TeachingRatings dataset and examine its structure and observations.

### 3. Identify Duplicate Observations
Identify duplicate records using the professor identifier.

### 4. Compare Age Statistics
Calculate the mean age and standard deviation using all observations and compare them with the statistics after removing duplicate professor records.

### 5. Average Teaching Evaluation by Division
Calculate the average teaching evaluation scores for different course divisions and visualize the results using a bar chart.

### 6. Relationship Between Age and Evaluation
Create a scatter plot to visualize the relationship between professor age and teaching evaluation scores.

### 7. Analyze Age, Evaluation and Gender
Create a scatter plot using gender to compare teaching evaluation scores across age groups.

### 8. Analyze Age, Evaluation, Gender and Tenure
Create a scatter plot using gender and tenure to examine the distribution of evaluation scores across different categories.
