# Practical 6: T-Test, ANOVA, Chi-Square and Correlation

## Aim
To perform statistical hypothesis testing and analyze relationships between variables using T-test, ANOVA, Chi-square test and correlation.

## Objectives
- Understand statistical hypothesis testing.
- Perform T-tests.
- Apply ANOVA to compare group means.
- Perform Chi-square tests of independence.
- Calculate Pearson correlation.
- Interpret p-values and statistical significance.

## Libraries Used
- **Pandas:** Used for data manipulation.
- **NumPy:** Used for numerical calculations.
- **SciPy:** Used for statistical testing.
- **Matplotlib:** Used for visualization.
- **Seaborn:** Used for statistical graphs.

## Dataset
TeachingRatings.csv

## Practical Implementation

### 1. Import Libraries
Import the required Python libraries for statistical analysis and visualization.

### 2. Load Dataset
Load and explore the TeachingRatings dataset.

### 3. Perform T-Test
Perform a T-test to compare relevant groups and determine whether the difference between their means is statistically significant.

### 4. Perform ANOVA
Apply ANOVA to compare beauty scores across different age groups and examine whether significant differences exist.

### 5. Perform Chi-Square Test
Create a contingency table for tenure and gender and perform the Chi-square test of independence to examine their association.

### 6. Perform Correlation Analysis
Calculate Pearson correlation between teaching evaluation scores and beauty scores.

### 7. Visualize Correlation
Create a regression plot to visualize the relationship between teaching evaluation scores and beauty scores.

### 8. Interpret Results
Interpret statistical results using test statistics, p-values and significance levels.
