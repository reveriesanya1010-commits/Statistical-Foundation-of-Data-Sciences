# Practical 3: Understanding Descriptive Statistics

## Aim
To understand descriptive statistics and analyze the Student Rating Dataset using Python and data visualization techniques.

## Objectives
- Explore the columns of a dataset.
- Calculate percentages using Pandas.
- Calculate mean and standard deviation.
- Analyze data based on different age groups.
- Visualize data using histograms and bar charts.
- Understand median evaluation scores.

## Libraries Used
- **Pandas:** Used for data manipulation and analysis.
- **NumPy:** Used for numerical calculations.
- **Matplotlib:** Used for creating graphs.
- **Seaborn:** Used for data visualization.

## Dataset
StudentRatingDataset_evals.csv

## Practical Implementation

### 1. Import Libraries
Import the required Python libraries for data analysis and visualization.

### 2. Load and Explore Dataset
Load the Student Rating Dataset and explore its structure, columns and observations.

### 3. Calculate Percentages
Use Pandas to calculate percentages for selected variables.

### 4. Calculate Descriptive Statistics
Calculate mean and standard deviation for numerical variables.

### 5. Group Data by Age
Group observations according to age and calculate relevant statistical measures.

### 6. Visualize Data
Create histograms and bar charts to represent the data graphically.

### 7. Calculate Median Evaluation
Calculate the median evaluation score to understand the central value of the dataset.
